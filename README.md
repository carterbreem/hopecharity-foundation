# Hope Charity Foundation

Official website for Hope Charity Foundation — providing compassionate assistance to individuals and families in need.

## Setup

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env` and fill in your Supabase credentials
3. Run dev server: `npm run dev`
4. Build for production: `npm run build`

## Environment Variables

- `VITE_SUPABASE_URL` — Supabase project URL
- `VITE_SUPABASE_ANON_KEY` — Supabase anon public key

## Deployment

Deployed on Vercel. Set the environment variables above in
Vercel → Project → Settings → Environment Variables before deploying.
